# תרחישי שימוש מרכזיים — בריא.ה אפליקציה

## 1. חברה חדשה מצטרפת (Onboarding)

1. חברה נרשמת למנוי (היום: דרך ארבוקס / שיחת אבחון עם רוני/ניצן).
2. חברה מקבלת קישור לאפליקציה → חותמת טופס הסכמה + טופס שיתוף מידע צוותי (חובה לפני כל שימוש).
3. ממלאת שאלון קליטה.
4. ניצן משבצת לה מלווה.
5. פגישת מלווה ראשונה (30 דק', בפועל/זום): המלווה בונה איתה תוכנית אישית (על בסיס חמשת הרבדים) ורושמת הערות/תוכנית באפליקציה.
6. בסוף החודש הראשון: שיחת בדיקה להמשכיות (חידוש התחייבות ל-3 חודשים).

## 2. שימוש יומיומי של מלווה

1. מלווה נכנסת לאפליקציה → רואה רשימת החברות המשובצות אליה, ממוינת לפי "דורש תשומת לב" (למשל: לא הייתה פעילה החודש, או שיחת בדיקה מתקרבת).
2. פותחת כרטיס חברה → רואה: שלב במסע, תוכנית אישית, הערות קודמות (שלה + הערות "כלל-צוותי" מאחרות), מפגשים אחרונים (מארבוקס אם מחובר).
3. כותבת הערה חדשה → בוחרת visibility (כלל-צוותי/מוגבל) → שומרת.
4. לפני פגישת מעקב חודשית: המלווה סוקרת את ההיסטוריה כדי להגיע מוכנה.

## 3. שימוש של מתרגל 1:1

1. נכנס → רואה רשימת הלקוחות שלו (חברות שקבעו איתו מפגשי 1:1).
2. לפני מפגש: רואה הערות מסדנאות קבוצתיות + הערות מלוות ששותפו איתו על אותה חברה.
3. אחרי מפגש: כותב סיכום מפגש מובנה (נראה רק לניצן כברירת מחדל).
4. אם עולה משהו חשוב שצריך להגיע לצוות הרחב יותר → מסמן "קריטי להעביר הלאה".

## 4. שימוש של מנחה סדנה קבוצתית

1. לפני סדנה: רואה רשימת משתתפות + כל הערה שסומנה "קריטי" עליהן, וגם הערות ששותפו איתו במפורש (למשל "שימי לב, X עוברת תקופה רגישה").
2. לא רואה את מלוא ההיסטוריה של החברה — רק מה שרלוונטי לסדנה הזו.

## 5. מסך הבית של חברה (עתידי, לא MVP ראשון)

1. נכנסת לאפליקציה → רואה ציטוט יומי, שמה, שיעורי השבוע.
2. יכולה לגשת ללוח הזמנים/הרשמה (דרך deep-link לארבוקס).
3. רואה את התוכנית האישית שלה ("איפה אני בתהליך").
4. יכולה לשלוח הודעה למלווה שלה.
5. (עתידי) רואה כמה מפגשים מהמנוי נוצלו החודש.
6. (עתידי, רגיש) גישה לכלי AI בטון של בריא.ה לרגעי מצוקה — **לא ל-MVP, דורש חשיבה על גבולות אחריות ובטיחות.**

## 6. דיווח וחיוב חודשי של מתרגל/מנחה

1. במהלך החודש (או בסופו) המתרגל/ה נכנס/ת לאפליקציה ומזין/ה את רשימת הטיפולים/סדנאות שהעביר/ה.
2. מצרף/ת קבלות רלוונטיות אם יש (העלאת קובץ).
3. שולח/ת את הדיווח — הוא מגיע כ"דוח" לרוני.
4. רוני עוברת על הדיווח מול מה שהיא יודעת שהתקיים בפועל, ומסמנת סטטוס: שולם / לא שולם / שולם חלקית — יכולה להוסיף הערה.
5. המתרגל/ה רואה בכל רגע את סטטוס התשלום של הדיווחים שלו/ה.

זה מחליף את התהליך הידני שקיים היום ב-Excel לחיוב מתרגלים. שימו לב: זה לא תלוי בחיבור לארבוקס ולא נוגע במידע טיפולי — לכן זה מועמד טוב לבנייה מוקדמת/מקבילה למודול המלווה.

## 7. תרחיש קצה חשוב: חברה עוזבת / מקפיאה מנוי

- לא תואר לעומק בבריינסטורם — צריך להחליט: מה קורה להערות/לתוכנית שלה (נשמר? מוסתר? נמחק לפי בקשה?), האם המלווה מקבלת עדכון, איך זה מסתנכרן מול ארבוקס.
