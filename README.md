# בריאה — ניהול קהילה

אפליקציית web לניהול קהילת הוולנס "בריאה" בתל אביב: לוח שנה, רשימת אירועים וצוות.
בנויה עם React + Vite, כל הנתונים נשמרים ב-localStorage של הדפדפן.

## הרצה

```bash
npm install
npm run dev
```

## בנייה לפרודקשן

```bash
npm run build
```

## מבנה נתונים

- אירועים קבועים (פתיחת/סגירת מחזור, יוגה שבועית, מעגל בריאה, הרצאה, ישיבת צוות, הדרכה, פגישת מלווים, חגים) נוצרים אוטומטית בכל חודש החל מאוגוסט 2026.
- אירועים שמוסיפים ידנית, וכן צוות הקהילה, נשמרים ב-localStorage בדפדפן בלבד (אין שרת/מסד נתונים).
