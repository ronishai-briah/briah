# בריאה — מערכת גאנטים

אפליקציית web לניהול קהילת הוולנס "בריאה" בתל אביב: שלושה גאנטים (צוות וניהול, שיווק ותוכן, כלכלי) שמציגים את כל האירועים והמחזורים בפריסת ציר זמן אחת.
בנויה עם React + Vite, כל הנתונים נשמרים ב-localStorage של הדפדפן.

## הרצה

```bash
npm install
npm run dev
```

## בנייה לפרודקשן

```bash
npm run build
```

## מבנה נתונים

- **מחזורים**: מחזור 1–4 מוגדרים באופן קבוע (`src/data/cycles.js`), ומ-1.1.27 נפתח מחזור חדש כל חודש אוטומטית. תאריך סגירת הרשמה מחושב/מוגדר לכל מחזור.
- **אירועים קבועים**: דד-ליין לוז לצוות (15 לחודש), יוגה שבועית, מעגל בריאה, הרצאה, ערב צוות, הדרכה, ישיבת צוות וחגים נוצרים אוטומטית מדי חודש. אלו הנחות ברירת מחדל לגבי יום בשבוע/שבוע בחודש — ניתן לערוך כל מופע דרך הממשק.
- **שלושה גאנטים**: כל אירוע קבוע/מחזור משויך לגאנט הרלוונטי (`ganttIds`); אירועים מותאמים אישית משויכים לגאנט שבו נוצרו.
- **עריכה ומחיקה**: גם לאירועים קבועים — עריכה נשמרת כ"override" ומחיקה מוסתרת רק בדפדפן שלך; ניתן לשחזר לברירת מחדל.
- כל הנתונים (אירועים מותאמים אישית, עריכות ומחיקות) נשמרים ב-localStorage בלבד (אין שרת/מסד נתונים).
